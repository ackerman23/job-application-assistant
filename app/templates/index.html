Job Application Assistant

Flask is the primary web application. FastAPI provides a thin MCP/tooling service, and the old Streamlit prototype is retained only as a legacy reference.

Available entrypoints
  • Flask dashboard: /dashboard
  • Flask UI: /
  • Health check: /health
  • Profiles: /profiles/
  • Jobs: /jobs/analyze
  • Applications: /applications/
  • Documents: /documents/generate-cv
  • MCP server: http://127.0.0.1:8000

Open the dashboard to edit the profile, paste a job description, review evidence matches, and generate the tailored CV.

This app keeps the evidence-first workflow: profile evidence → job analysis → match scoring → tailored CV generation.
